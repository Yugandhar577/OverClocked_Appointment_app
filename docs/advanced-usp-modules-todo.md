# Advanced USP Modules TODO

Scope: extend the existing FastAPI + React appointment app in a backward-compatible way. Existing routes, request/response shapes, pages, components, models, and workflows must remain stable. New behavior must be modular, optional, feature-flagged, and covered by safe Alembic migrations.

Feature flags to add in `SRC/Backend/config.py`, `.env.example`, and a frontend feature-flag helper in `SRC/Frontend/src/lib/featureFlags.ts`: `ENABLE_WAITLIST`, `ENABLE_BOOKING_CART`, `ENABLE_VARIABLE_DURATION`, `ENABLE_RECURRING_BOOKINGS`, `ENABLE_NO_SHOW_PROTECTION`, `ENABLE_SMART_ASSIGNMENT`, `ENABLE_DYNAMIC_PRICING`, `ENABLE_NOTIFICATION_WORKFLOWS`, `ENABLE_ADMIN_MANUAL_BOOKING`, `ENABLE_APPOINTMENT_ANALYTICS`, `ENABLE_THEME_CUSTOMIZATION`, `ENABLE_ODOO_STYLE_UI`.

Definition of done: old booking flow still works, old pages render, no destructive migrations, every major module can be toggled off, admin-only features use RBAC, customer-facing features only appear when enabled, business logic stays in `services/`, APIs are additive under modular routes, seed/demo data exists, critical unit/integration/e2e tests pass, and documentation explains each module.
